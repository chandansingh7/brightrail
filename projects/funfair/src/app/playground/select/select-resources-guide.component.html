Select: forms and content projection

Use [ngModelOptions] when you bind ngModel on brightrail-select outside a <form> so Angular treats the control as standalone. Customize the trigger and menu with the projection slots below.

ngModel outside <form>

Without this, Angular expects a name attribute or a parent NgForm/FormGroupDirective. The playground defines readonly ngModelStandalone = { standalone: true }; and passes [ngModelOptions]="ngModelStandalone" on each select.

Projection slots

.br-select-prefix
Content before the value label (flags, icons, avatars).
.br-select-suffix
Content after the value, still inside the trigger (e.g. calendar icon before the chevron).
.br-select-value-slot
Replaces the default single-line value with custom markup (e.g. multi-select pill row). Use this class so the trigger hides the plain label (plain brSelectValue is unreliable in the DOM because HTML lowercases attribute names).
.br-select-panel
The dropdown body: typically buttons or a list. Click handling is yours; wire ngModel / ngModelChange from your options.
