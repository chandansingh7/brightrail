Inset label (border notch)

Material-style outlined field where the label sits on the top border and the stroke appears to break around the text. Pair labelPosition="inset" with appearance="outlined" for the intended look.

When to use

  • Dense forms where a separate label row would waste vertical space.
  • Designs that require a clear “outlined” affordance with the label tied to the field edge.
  • Works best with single-line inputs; multiline (rows > 1) is supported but the notch reads less like Material’s default.

Key inputs

labelPosition="inset"
Renders the label inside the control chrome on the top border.
appearance="outlined"
Recommended; provides the white fill and stroke the notch is drawn against.
iconLeft="user" (or any icon)
Optional leading icon inside the field, before the text.
[required]="true"
Shows an asterisk after the label, sets required and aria-required on the control.

Theming (CSS variables)

Override host tokens on brightrail-text-field (or a wrapper class). The live sample below uses coral accents; defaults follow the library host variables in brightrail-text-field.component.scss.

  • --br-tf-border, --br-tf-border-hover — rest / hover stroke
  • --br-tf-focus — focus border and ring (ring uses color-mix with this token)
  • --br-tf-label — inset label text color (and related label tone)
  • --br-tf-inset-label-bg — optional notch “cut-out” fill (defaults by appearance)
